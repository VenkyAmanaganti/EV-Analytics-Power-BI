1. PROJECT BACKGROUND
================================================================

This project explores electric vehicle (EV) data using Power BI. The report
organizes vehicle and market information into four dashboard pages:
Market Dashboard, Technical & Performance Analysis, Market & Pricing
Analysis, and Customer & Safety Analysis.

The goal is to make it easier to explore:
- EV records by manufacturer, vehicle type, country, and release year
- Vehicle prices and driving ranges
- Battery capacity and charging time
- Performance and efficiency attributes
- Safety ratings, seating capacity, and cargo space
- Differences between vehicle groups using interactive filters

This project demonstrates data analytics and business intelligence skills,
including data preparation, KPI design, data visualization, and dashboard
documentation.

================================================================

Field descriptions:

- model: vehicle model.

- fuel_type: fuel or powertrain category as represented in the source.
- color: vehicle color.

- range_km: driving range in kilometers.
- charging_time_hr: charging time in hours.
- fast_charging: indicator for fast-charging availability.
- release_year: release/model year recorded in the dataset.
- country and city: geographic attributes associated with the record.
- seats: passenger seating capacity.
- price_usd: vehicle price in US dollars.
- efficiency_score: vehicle efficiency score.
- acceleration_0_100_kmph: acceleration measure from 0 to 100 km/h.
- top_speed_kmph: maximum speed in kilometers per hour.
- warranty_years: warranty duration in years.
- cargo_space_liters: cargo capacity in liters.
- safety_rating: vehicle safety rating.
- target_high_efficiency: high-efficiency classification.

Note: Confirm field definitions and units against the dataset source or
project requirements before using the data for formal business decisions.

================================================================
4. PHASE 2 - DATA PREPARATION (POWER QUERY)
================================================================

STEP 1: Import the CSV
----------------------
1. Open Power BI Desktop.
2. Select Home > Get Data > Text/CSV.
3. Browse to EV_dataset.csv.
4. Preview the data and select Transform Data to open Power Query.

STEP 2: Verify Column Names and Data Types
------------------------------------------
1. Confirm all 22 expected columns are present.
2. Set numeric fields to appropriate numeric data types.
3. Set manufacturer, model, type, country, city, drive_type, fuel_type,
   and color to suitable text data types.
4. Check release_year is interpreted as a year value.
5. Verify fast_charging and target_high_efficiency use appropriate logical
   or categorical data types based on the actual source values.

STEP 3: Check Data Quality
--------------------------
1. Use Power Query column quality/profile tools where appropriate.
2. Check for null or blank values.
3. Check for duplicate records.
4. Inspect unexpected categories and inconsistent text values.
5. Check numeric fields for implausible values and outliers.
6. Review price_usd for negative or zero values and determine whether they
   are valid, placeholders, or errors.
7. Check that measurements use consistent units.

STEP 4: Apply Appropriate Cleaning
----------------------------------
1. Correct data types and trim/clean text values where needed.
2. Remove or correct invalid records only after confirming the issue.
3. Handle missing values according to the analysis requirement.
4. Keep a record of cleaning decisions so the work is reproducible.
5. Select Close & Apply when the data is ready.

Important: Do not remove records just because a value looks unusual.
First verify whether it is an error or a legitimate observation.

5. PHASE 3 - DATA ANALYSIS AND DAX (POWER BI)
================================================================

Create measures that match the question being answered. Example measures
are provided below; verify the table name in your own Power BI model.

Measure 1 - Total EV Records
----------------------------
Total EV Records = COUNTROWS('EV_dataset')

This counts rows in the table. It should only be described as a count of
unique vehicles if each row is known to represent a unique vehicle or a
reliable unique identifier is available.

Measure 2 - Average Price
-------------------------
Average Price = AVERAGE('EV_dataset'[price_usd])

Format as currency (USD) in the model or visual.

Measure 3 - Average Range
-------------------------
Average Range = AVERAGE('EV_dataset'[range_km])

Use kilometers as the displayed unit.

Measure 4 - Average Battery Capacity
------------------------------------
Average Battery Capacity = AVERAGE('EV_dataset'[battery_kwh])

Use kWh as the displayed unit.

Measure 5 - Average Charging Time
----------------------------------
Average Charging Time = AVERAGE('EV_dataset'[charging_time_hr])

Use hours as the displayed unit.

Measure 6 - Average Efficiency Score
------------------------------------
Average Efficiency Score = AVERAGE('EV_dataset'[efficiency_score])

Confirm the scale and meaning of the efficiency score before interpreting it.

Measure 7 - Average Safety Rating
---------------------------------
Average Safety Rating = AVERAGE('EV_dataset'[safety_rating])

Confirm the rating scale before interpreting the result.

Measure 8 - Average Cargo Space
-------------------------------
Average Cargo Space = AVERAGE('EV_dataset'[cargo_space_liters])

Use liters as the displayed unit.

These are example measures. Adapt them to the actual table name and report
requirements. Use suitable aggregations and avoid summing measures such as
price or driving range when an average or median answers the question better.

7. DATA QUALITY CHECKS
================================================================

The dashboard screenshots indicate issues that should be reviewed before
presenting conclusions:

1. Negative Minimum Price
   The Market & Pricing page appears to show a minimum price around -5K.
   Inspect the underlying price_usd records and determine whether this is an
   invalid value, placeholder, calculation issue, or filter effect.

2. Aggregation of Price and Range
   Some chart axes appear to use sums of price_usd or range_km. Summing
   vehicle prices or ranges across unrelated records can be misleading.
   Confirm whether average, median, count, or another aggregation is suitable.

3. Truncated Titles and Labels
   Expand chart titles and KPI labels so the metric and unit are clear.

4. Nearly Uniform Safety or Efficiency Visuals
   Verify the field placed in the visual, its aggregation, number formatting,
   and the effect of slicers.

5. Release-Year Aggregation
   Confirm release_year is used to group or filter records, not unintentionally
   summed as a numeric measure.

6. Metric Definitions
   Verify the scale and meaning of safety_rating and efficiency_score before
   describing one value as better than another.

These are checks suggested by the screenshots, not confirmed defects in the
source data. Validate each item against the raw CSV and Power BI model.

11. LIMITATIONS AND FUTURE IMPROVEMENTS
================================================================

Limitations:
- The dashboard describes the supplied dataset and may not represent the
  entire EV market.
- Results depend on data quality and field definitions.
- Chart relationships do not prove causation.
- Comparisons can be misleading when vehicle groups differ substantially.

Future improvements:
- Add median price and range alongside averages.
- Add a dedicated data-quality page.
- Add drill-through pages and informative tooltips.
- Document KPI formulas and definitions in the report.
- Add year-over-year comparisons where the data supports them.
- Create manufacturer rankings with transparent criteria.
- Automate checks for missing, duplicate, and invalid values.
